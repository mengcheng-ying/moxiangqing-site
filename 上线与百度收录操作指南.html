《墨香情》官网 · Cloudflare Pages 上线与百度收录指南

真实架构：GitHub 存代码 → Cloudflare Pages 托管（项目 mxq）→ 自定义域 mxq.fmbly.com

当前进度确认

你的 Cloudflare Pages 项目 mxq 已创建，正在验证自定义域 mxq.fmbly.com（验证最长 48 小时）。 本站所需文件（index.html 根入口 + assets + robots.txt + sitemap.xml）已全部就绪，Sitemap 地址已指向真实域名 https://mxq.fmbly.com/。

第一步 · 确认 Cloudflare 连接的 GitHub 仓库 关键

1

检查项目 mxq 连接的是哪个仓库

截图显示连接的是 mengcheng-ying/moxiangshui，但本站代码当前提交在仓库 mengcheng-ying/moxiangqing-site。二者必须一致，否则部署的是旧内容。

Cloudflare Pages → 项目 mxq → 设置 → 关联的 Git 仓库：

若连的是 moxiangshui：把本站代码提交推送到 moxiangshui 仓库（见第二步）。

若连错仓库：点「连接到仓库」改选 moxiangqing-site，或在 Cloudflare 上换到正确的仓库。

第二步 · 推送代码到 Cloudflare 连接的仓库

2

提交并推送本站全部文件

确保仓库里的核心文件是：index.html（根入口）、assets/、_shared/、robots.txt、sitemap.xml。

git add -A git commit -m "墨香情官网：整合资讯+SEO 文件，适配 Cloudflare Pages" git push origin main

Cloudflare Pages 会在 push 后自动重新部署（无需手动触发）。

第三步 · 等自定义域验证完成

3

等待 mxq.fmbly.com 验证与 DNS 生效

  • Cloudflare 显示「正在验证」属正常，最长 48 小时生效，通常几分钟到几小时。
  • 验证通过后，输入 https://mxq.fmbly.com/ 能打开官网即部署成功。
  • 若一直停在"完成 DNS 设置"，按 Cloudflare 提示点开，补一条 CNAME 或 A 记录（若域名在外部解析需去对应服务商配）。

第四步 · 提交给百度收录

4

百度搜索资源平台提交

  • 打开 ziyuan.baidu.com，百度账号登录 → 「站点管理」→ 添加站点
  • 站点地址填 https://mxq.fmbly.com/
  • 验证方式选 HTML 标签验证：复制验证 Meta 到 index.html 的 <head> 里，重新 push（Cloudflare 自动重部署）
  • 验证通过 → 「链接提交」普通收录：
  • ① sitemap 提交：https://mxq.fmbly.com/sitemap.xml
  • ② 手动提交：提交 https://mxq.fmbly.com/

第五步 · 检测收录

5

查询是否被百度收录

site:mxq.fmbly.com

首次提交后百度通常 3-25 天内收录。此后更新内容时同时刷新 sitemap 并重新推送即可。

必须注意的红线

  • 仓库一致：Cloudflare 连接仓库 与 代码所在仓库必须相同，否则线上不是最新版。
  • 根入口 index.html 必须有：Cloudflare Pages 访问根域名默认找 index.html（目前已建好）。
  • 强制 HTTPS：Cloudflare 「Enforce HTTPS」建议开启，百度信任 https。
  • 别堆重复页：单页官网即可，别做大量重复内容页面。
